| L39 | WHEN adding a test seam (env var, parameter) that points a safety guard at a fixture → DO add the fixture to the protected set and keep the real target in it, NOT replace the real target with the seam's value (measured: `SPIKE_CORPUS_FROZEN_PATH` replaced the frozen corpus path, so a bare run with the hook set would have overwritten gitignored evidence, and the suite stayed green under a mutation of the default) | render-bisect (PR #53) |

| L45 | WHEN a repo gate judges whole modified lines for a banned character → DO leave a list item or table row byte-identical and put the new text on its own line, and in a one-line paragraph rewrite only the banned character and say so, NOT rewrite it in place across siblings (measured: rewriting one em dash made `Phase 2` the only numbered phase without one; the three long snippet lines had no other option and 6 dashes were rewritten) | confirm-via-question-tool (PR #56) |
| L54 | WHEN a test proves a fix by an exit code that other failures also produce (exit 2 with the usage line) → DO also assert the message only the fixed path prints, NOT the exit code alone (measured: the old copy-rules fallback also exited 2 with the usage line when its checkout had no local `main`, so the no-repository test would have passed on the bug in such a clone) | copy-rules-root (PR #89) |

| L73 | WHEN a gate judges what is staged → DO read every input it compares against (baseline, config, attributes) from the index too, NOT from the working tree (measured: ceilings read from the working tree let an unstaged ceiling raise pass the hook; the reviewer found it, fixed RED-first in cb57fd5) | file-size-gate (PR #114) |
