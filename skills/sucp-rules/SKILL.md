# Shared Operating Rules

> Part of `super-ultra-code-plan`. Entry point and phase router: the `super-ultra-code-plan` skill. Phase skills: `sucp-brainstorm`, `sucp-plan`, `sucp-tdd-debug`, `sucp-verify-deliver`, `sucp-debt-sweep`.

## 📚 Required reading

This skill is split into reference files because of the 5,000-token file limit. Every file below MUST be read in full, in order, before acting. A session that has not read them all has not loaded this skill. Nothing here is on-demand reading: the rules in each file apply to every run.

3. [references/03-tool-orchestration.md](references/03-tool-orchestration.md): Tool orchestration.
4. [references/04-token-reasoning.md](references/04-token-reasoning.md): Token-efficient execution; reasoning, research and scope.
5. [references/05-delegation.md](references/05-delegation.md): Delegation and execution.
6. [references/06-quality-output.md](references/06-quality-output.md): Quality, generality and cleanup; output, documentation and handoff.
7. [references/07-completion-confirmation.md](references/07-completion-confirmation.md): Approved-work completion and the Confirmation Protocol.
8. [references/08-learning-frontend.md](references/08-learning-frontend.md): Continuous learning and memory lifecycle; frontend-only aesthetic rules.
