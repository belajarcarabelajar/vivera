# Contoh

Lihat folder [`examples/`](https://github.com/belajarcarabelajar/vivera/tree/main/examples) untuk walkthrough lengkap yang sudah terisi:

- **[`worked-example.md`](https://github.com/belajarcarabelajar/vivera/blob/main/examples/worked-example.md)**: Pipeline penuh dari Classify sampai debt sweep (penyisiran utang) saat penutupan sesi, pada tugas berukuran nyata (menambahkan validasi input zod ke sebuah endpoint REST). Gunakan ini sebagai acuan bentuk output yang benar di setiap fase.
- **[`deep-research-worked-example.md`](https://github.com/belajarcarabelajar/vivera/blob/main/examples/deep-research-worked-example.md)**: Laporan riset berbasis sitasi dengan panjang dan kepadatan sesuai target.
- **[`graph-viewer-demo.md`](https://github.com/belajarcarabelajar/vivera/blob/main/examples/graph-viewer-demo.md)**: Penampil knowledge graph yang dipakai bersama pipeline vault, dalam bentuk demo HTML mandiri dengan data sintetis ([`graph-viewer-demo.html`](https://github.com/belajarcarabelajar/vivera/blob/main/examples/graph-viewer-demo.html), berjalan offline).
