# eval-review

Shopping cart helpers.

- `totalQuantity(items)` returns the sum of `qty` over all items.
- `applyDiscount(price, rate)` returns the price after a discount, where `rate` is a fraction such as 0.2 for 20 percent off.
- `averagePrice(items)` returns the mean `price` of the items, and 0 for an empty cart.
